Cross-cutting Capability

Agent 운영에 필요한
평가·권한·추적 기준을 설계합니다

정확성, 권한, 근거 추적, 중단 조건, 비용과 변경 절차를 배포 전에 정의합니다.

AgentOps는 Build와 Application Service에 공통으로 적용하는 운영 역량입니다. Build 단계에서는 평가·권한·추적 구조를 구현하고, Application Service 단계에서는 모니터링, 장애 대응, 변경 관리와 개선을 수행합니다.

적용 대상
  • —Agent를 실제 업무에 배포하려는 기업
  • —기존 Agent의 정확성·권한·비용·감사가 불명확한 기업
  • —사용 결과를 다음 개선으로 연결하려는 기업
운영·통제 항목

역량내용산출물

평가와 권한, 추적 기준은 배포 전에
정해야 합니다.

운영 기준을 나중에 보완할 수도 있지만, 이미 만든 Agent와 업무 절차를 다시 손봐야 해 비용과 위험이 커집니다.

데이터 접근 권한 자체의 설계는 Snowflake Data & AI의 접근권한·보안 설계에서 다룹니다. AgentOps는 그 위에서 Agent의 실행 통제와 감사를 담당합니다.

현재 상태를 먼저 진단하고 필요한 통제와 운영 기준을 보완합니다.
