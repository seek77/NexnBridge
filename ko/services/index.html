Services

계약 목적과 책임 범위에 따라
서비스를 구분합니다

Consulting, Build, Application Service는 수행 범위와 완료 기준, 운영 책임이 서로 다릅니다.

Service Types

세 가지 서비스 유형

서비스 유형답하는 질문주요 범위완료 기준
Consulting무엇을 왜 바꿔야 하는가?현황 진단 · PI · 의사결정 구조 · Target Architecture · Roadmap합의된 방향, 우선순위, 기준, 추진계획
Build고객 업무와 환경에 무엇을 구현할 것인가?설계 · 개발 · 통합 · 검증 · 배포 · 전환고객 환경에 구현된 시스템과 운영 기준
Application Service무엇을 지속해서 사용·운영할 것인가?업무 Application · 업데이트 · FinOps·기술지원사용할 수 있는 서비스와 합의된 운영 범위·SLA
01

Consulting

구축 범위를 정하기 전 현재 업무와 데이터, 판단 기준, 우선순위를 확인합니다. 진단과 로드맵 수립만으로 Consulting을 완료할 수 있습니다.

02

Build

고객별 요구와 시스템 환경에 맞춰 지식, 데이터 기반, Agent, Application을 설계하고 구현합니다. 프로젝트 범위와 인수 기준을 정해 수행합니다.

03

Application Service

표준화한 업무 Application과 모듈, Snowflake FinOps·기술지원을 지속 제공합니다. 고객별 구축 프로젝트와 구분합니다.

배포 환경을 뜻하지 않습니다 같은 서비스도 Managed SaaS · Customer Cloud · Hybrid 중 적합한 방식으로 제공할 수 있습니다. 계약 방식(무엇을 어떻게 사는가)과 제공 환경(어디서 누가 운영하는가)은 별개입니다.
Core Service Areas

핵심 서비스 영역

전문영역맡는 일대표 결과물
Enterprise Knowledge Engineering 업무 개념, 관계, 규칙, 근거, 예외 정리 Business Ontology · Knowledge Graph · Decision Architecture
★ Snowflake Data & AI Services AI-Ready 데이터 기반, SAP 전환, 데이터 모델, 연계, Semantic Analytics·AI, 접근권한·보안 설계, 비용 최적화(FinOps), 기술지원 Data Foundation · Migration · Data Model · Semantic Layer · Security & Access Design · Cost Optimization · Managed Service
Agentic Solution Engineering 업무 Agent, 최적화, Application, Workflow 구현 업무 Agent · Decision App · Optimisation · Workflow

핵심 서비스 영역은 고객 과제의 내용을, 서비스 유형은 계약 목적과 책임 범위를 구분합니다. 한 영역에서 Consulting, Build, Application Service를 연계할 수 있습니다.

Snowflake Data & AI는 진단과 목표 구조 수립, 데이터 기반 구축과 SAP 전환, FinOps·Managed Service를 포함합니다. AgentOps는 Build와 Application Service에 공통으로 적용하는 운영역량입니다.
