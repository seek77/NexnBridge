AI-Ready Data Foundation

데이터의 복잡성을 줄이고 업무 의미를 명확하게 정의합니다

AI가 물리 테이블과 컬럼의 구조를 직접 해석하게 하지 않습니다. 중복된 데이터 구조와 계산 기준을 정리하고, 업무 객체와 관계, 지표와 권한을 명확하게 정의합니다.

이를 통해 Analytics와 AI가 같은 업무 용어와 계산 기준으로 데이터를 사용할 수 있도록 합니다.

Data Rationalization

중복된 데이터마트, 테이블, 코드와 계산식을 분석하고, 실제 활용 목적에 필요한 데이터와 이력 범위를 정합니다.

데이터를 단순히 삭제하거나 축소하는 것이 아니라, 동일한 의미를 여러 시스템에서 다르게 관리하면서 발생하는 복잡성을 줄입니다.

Enterprise Data Model & Standards

Domain, Master, Transaction과 History를 구분하고 Grain, Key, Code, Naming과 공통 Dimension 기준을 정합니다.

물리·논리 데이터 모델은 데이터의 저장 구조와 계산 기반을 담당합니다.

Semantic Layer & Semantic Views

Snowflake Semantic Views에 업무 객체, 관계, Dimension, Fact, Metric과 계산 기준을 정의합니다.

업무 설명, 동의어, Verified Query와 분석 지침을 함께 관리해 BI와 AI가 동일한 업무 의미를 사용하도록 합니다.

Semantic View는 물리·논리 데이터 모델을 대신하지 않습니다. 검증된 데이터 모델 위에서 업무 사용자가 이해하는 의미와 분석 기준을 제공합니다.

Governance, Security & Lineage

데이터 품질, 계보, 소유자, 접근권한, 민감정보 보호와 변경관리 기준을 적용합니다.

AI가 접근할 수 있는 데이터와 사용할 수 없는 데이터를 역할과 업무 목적에 따라 구분합니다.

AI Access & Evaluation

정형 데이터는 Semantic Views와 Cortex Analyst를 통해 자연어 분석에 활용할 수 있도록 구성합니다.

문서와 규정 같은 비정형 데이터는 메타데이터와 Cortex Search를 적용해 검색, RAG와 Agent가 사용할 수 있도록 준비합니다.

대표 업무 질문과 검증된 SQL을 기준으로 분석 정확도를 점검하고 Semantic Layer를 지속적으로 보완합니다.
