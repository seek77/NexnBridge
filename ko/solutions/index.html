적용 방식 판단 기준

업무의 성격권장 방식
절차가 고정돼 있고 예외가 거의 없다Workflow 또는 Rule Engine
입력과 출력이 명확한 반복 계산이다Procedure 또는 최적화 모델
상황에 따라 확인할 질문과 근거가 달라진다Agentic Analysis
여러 대안의 영향과 한계를 비교해 사람이 결정해야 한다KOAA와 Decision Brief

업무 특성에 따라 Workflow, Rule Engine, 최적화 모델 또는 Agentic Analysis 중 적합한 방식을 선택합니다.

분야가 달라도 공통으로 확인하는 것

결정할 문제 → 업무 기준 → 데이터 근거
→ 대안과 영향 → 사람의 결정 → 실행 결과

업무 용어와 지표는 분야마다 달라집니다. 다만 누가 무엇을 결정하고, 어떤 근거를 쓰며, 결과를 어떻게 확인할지는 같은 순서로 설계할 수 있습니다.
